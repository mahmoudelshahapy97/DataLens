Chat request flow: what happens when a question is submitted

  1. Browser: <vanna-chat> POSTs to /api/vanna/v2/chat_sse with the session cookie.
  2. FastAPI route: chat_sse builds a RequestContext and streams chunks over SSE.
  3. Tenant dispatch: resolves the user, picks the tenant runtime, optional BYO LLM key.
  4. Agent: hooks, conversation, workflow handler, tools, system prompt, then the turn graph.
  5. Turn graph: llm_turn → tools → llm_turn … → answer, with optional Planner and Critic nodes.
  6. Response: each UI component becomes a stream chunk rendered live in the browser.
